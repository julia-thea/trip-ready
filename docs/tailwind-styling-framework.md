# Tailwind Styling Framework

## 1. Layout

- Display: `flex`, `grid`, `block`
- Direction: `flex-row`, `flex-col`
- Alignment: `justify-between`, `items-center`
- Grid columns: `grid-cols-3`
- Gap: `gap-4`, `gap-8`

## 2. Spacing

- Padding: `p-4`, `px-8`, `py-4`
- Margin: `m-4`, `mx-auto`, `mb-6`

## 3. Sizing

- Width: `w-full`, `max-w-4xl`
- Height: `h-14`, `min-h-screen`

## 4. Typography

- Family: `font-sora`
- Size: `text-xl`, `text-5xl`
- Weight: `font-bold`, `font-semibold`
- Color: `text-navy`, `text-white`
- Align: `text-center`

## 5. Backgrounds & Borders

- Background: `bg-navy`, `bg-gradient-to-br`, `from-sky`
- Border: `border`, `border-silver`, `rounded-lg`

## 6. Effects

- Shadow: `shadow-lg`
- Opacity: `opacity-50`

## 7. Interactivity

- Hover: `hover:bg-navy`
- Transition: `transition-all`
- Transform: `hover:scale-105`

## Notes

- Horizontal spacing: Always use padding (px-8) to keep content from edges
- Vertical spacing without background: Use margin (my-10) to separate sections
- Vertical spacing with background: Use padding (py-8) so background fills the space
